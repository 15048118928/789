# 实习手记 · Internote

把每天的实习工作，沉淀成有原文依据的简历素材和面试案例。

在线使用：https://internote-daily-achievements.citrus-curry-9430.chatgpt.site/

## 功能

- 每日记录任务、背景、工作方法、卡点、交付结果和下次改进方法。
- 保存原始记录后自动调用 DeepSeek，生成可编辑的工作要点。
- AI 提出可选的补充问题，展示可验证的原文引用；提示新数字和职责拔高。
- 经历档案支持搜索、日期筛选、周报导出、回收与恢复。
- 卡点复盘按时间倒序展示，支持项目筛选、复制及经验沉淀。
- 同一项目的多天素材可以合并去重，保存为独立的简历项目成品并回溯来源。
- 浏览器本地草稿与 JSON 备份；可选账号云端同步、冲突副本保留及最近20次云端保存恢复。

## 快速开始

需要 Node.js 22 或更新版本。项目运行与检查无第三方 npm 依赖。

```sh
npm run build
npm test
```

构建输出为 `dist/server/index.js`，导出标准 Worker `fetch` 处理器。HTML、CSS、JavaScript 作为字符串嵌入 Worker；数据库结构位于 `drizzle/`。

本机页面预览需要 Python 3：

```sh
npm run preview
```

打开 http://127.0.0.1:5178/ 。这是静态界面预览，云端同步接口仅在完整托管环境中提供。本机真实 AI 调用需要浏览器可连接 DeepSeek，并在准备页填写自己的 API Key，按 DeepSeek 账户计费。

## 源码结构

```text
client/
  index.html       页面与每日记录表单
  app.js           记录、筛选、导出与原始数据
  preferences.js   首次准备页、API Key 与项目选项
  ai.js            基础 AI 界面与每日自动梳理入口
  review.js        卡点复盘模块
  growth.js        AI 追问、原文依据、跨天合并、经验沉淀
  cloud.js         云端同步、冲突合并、历史版本恢复
  polish.css      界面样式
worker/handler.mjs 登录隔离、数据库接口和静态资源服务
drizzle/          云端数据库结构迁移
.openai/hosting.json 现有 Sites 项目和数据库绑定
tests/            浏览器逻辑、模拟 AI 与 Worker 接口检查
build.cjs         无依赖构建脚本
```

## 发布与维护

当前线上网站由 Sites 托管。`.openai/hosting.json` 保留现有项目标识，`d1` 声明为 `DB`。在有该项目编辑权限的环境中，按 Sites 的源码同步、构建打包和发布流程更新，保持同一个项目标识以继续使用现有网址和数据库。

本仓库是源码归档，不会因 GitHub 提交自动更新线上网站。先修改 `client/` 或 `worker/`，执行 `npm test`，再构建并通过托管平台发布。不要直接编辑生成的 `dist/` 文件。

数据库迁移历史不可覆盖或删除；后续结构变化新增 SQL 和迁移日志。平台发布时应用迁移。不要在处理用户请求时执行建表或改表操作。

Worker 依赖托管平台校验后注入的 `oai-authenticated-user-id`。若迁移到其他托管环境，必须先实现可靠的登录和服务端身份验证，不能信任浏览器直接传入的同名请求头。仅把 Worker 上传到其他平台并不能直接获得现有账号与云端数据。

## 数据与密钥

- 这份仓库不包含用户记录、云端数据库内容、API Key 或 Git 凭据。
- DeepSeek API Key 由使用者在浏览器中填写，按用户此前选择保存在当前浏览器，不写入源代码、记录备份或云端记录。共享电脑上使用后可在设置中清除。
- AI 梳理时，所选原文和目标岗位直接发送给 DeepSeek；先移除不宜发送的公司机密或个人信息。
- 点击设置中的「连接云端并合并已有记录」后才开始同步；云端内容按网站登录账号隔离。
- GitHub 源码备份和实习数据备份是两回事。更新前建议从网站另行「导出备份」，将 JSON 文件保存在个人安全位置，不提交到代码仓库。
- 更换网址会改变浏览器存储范围；迁移时先导出旧网址记录，再在新网址导入。数据库迁移需要单独处理，不能通过复制源码自动完成。

## 检查范围

`npm test` 检查页面脚本启动、旧记录兼容、原文保留、模拟 AI 追问与跨天合并、同步冲突合并、接口身份校验、来源限制、版本冲突和账号隔离。

检查采用模拟浏览器与模拟数据库，不代表真实浏览器全流程、实际 DeepSeek 响应质量或真实多设备同步已通过端到端测试。上线后仍应以自己的测试记录走完整流程。
